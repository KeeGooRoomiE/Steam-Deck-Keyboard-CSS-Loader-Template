# Steam Deck Customizable Keyboard

A clean, modern, fully‑customizable keyboard theme for the Steam Deck.
Now also includes all keyboards from the Steam Points Shop.

## Presets

13 hand-tuned presets, selectable from the **Preset** dropdown:

- Inspired by Steam Points Shop keyboards:
  Steam Green · Spectrum · Cerulean · Digital · Seafoam · Candy Coded · Grape · Ruby · Pumpkin · OLED · Limited Edition White
- Plus **One Dark Style** and **OLED Black**
- Plus **Custom** — 9 colour pickers, corner radius, etc. to build your own from scratch

Each preset carries its own corner radius, glow/bevel and function-key styling — not just a flat recolour.
Two global controls: **Press animation** (on/off) and **Function keys** (accent / neutral).

## Install

1. Copy this folder into `~/homebrew/themes/`
2. Decky → **CSS Loader** → enable **Customizable Keyboard**
3. Press **Refresh Themes** if needed
