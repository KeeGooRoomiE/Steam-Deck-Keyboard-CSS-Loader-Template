# Customizable Keyboard — Plugin Package

This folder contains the ready‑to‑install version of the Customizable Keyboard theme for Steam Deck’s CSS Loader.

Drop this folder into:
```
~/homebrew/themes/
```
and the theme will appear in Decky → CSS Loader.

---

## Presets

13 hand-tuned presets, selectable from the **Preset** dropdown:

- Inspired by Steam Points Shop keyboards: **Steam Green · Spectrum · Cerulean · Digital · Seafoam ·
  Candy Coded · Grape · Ruby · Pumpkin · OLED · Limited Edition White**
- Plus **One Dark Style** and **OLED Black**
- Plus **Custom** — 9 colour pickers to build your own from scratch

Each preset carries its own corner radius, glow/bevel, and function-key styling — not just a flat
recolour. Two extra controls apply globally: **Press animation** (on/off) and **Function keys**
(accent / neutral).

## Included
- `theme.json` — CSS Loader manifest: presets + global controls + Custom colour pickers.
- `keyboard.css` — main stylesheet.

Styling reference (mappable properties and key states): `docs/keyboard-anatomy.md` in the repo root.

---

## Install
1. Copy this entire folder to `~/homebrew/themes/`
2. Open Decky → **CSS Loader**
3. Enable **Customizable Keyboard**
4. Press **Refresh Themes** if needed
